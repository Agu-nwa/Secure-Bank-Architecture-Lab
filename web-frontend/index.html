The frontend is public. The banking engine is private.

In a realistic AWS design, users reach an ALB. The ALB routes to private app servers. Those app servers call private services and private databases. Customers never directly reach the backend.

Request flow

1. Customer → Route 53 → CloudFront/WAF → ALB
2. ALB → Private web/app servers
3. App servers → Auth, Account, Transfer, Fraud services
4. Services → RDS, Redis, S3, CloudWatch
